# TASEMS — The Arqam Smart Education & Management System

**Owner:** The Arqam Schools (Samanabad head office, Faisalabad)
**Master plan:** "TASEMS — Software Development Master Plan" (shared doc, approved 16 Oct 2026). This folder holds the working source of truth derived from it.

## Purpose

One trusted system for The Arqam Schools' network: branches, students, staff, academics, attendance, diaries, exams, Hifz, admissions, fees and parent communication, with AI used where it saves teachers time and never to make unchecked decisions about a child.

## The organisation (confirmed 16 Oct 2026)

- 350+ branches, 250,000+ students, 20,000+ Hifz-e-Quran students; staff count varies by branch (Samanabad campus about 80–90).
- Two head offices, Faisalabad (Samanabad campus) and Lahore, each controlling its own regions/cities.
- Only the two head office campuses are company-owned; all other branches are franchises. Franchises collect fees; head office receives an 8% royalty on monthly collections and may see all franchise data (per franchise agreement).
- One syllabus across Pakistan, aligned with the government's Single National Curriculum.
- Today: both head offices use one in-house web system; student attendance is manual; staff attendance uses face-recognition biometric machines; fees are paid online, at school and at banks against printed vouchers.

## Scope of the MVP

Platform core · organisation and student records · student attendance · Daily Diary · AI Teacher Assistant · basic head-office dashboard. Pilot at the Samanabad campus first.

## Glossary

| Term | Meaning |
| --- | --- |
| Branch | One school campus (company-owned or franchise) |
| Head office (HO) | Faisalabad or Lahore; supervises its regions and branches |
| Session | One academic year, e.g. 2026-27 |
| Section | A class group in a session, e.g. Class 5-A |
| Enrolment | A student's placement in a section for one session |
| Sabaq / Sabqi / Manzil | New lesson / recent revision / older revision in Hifz |
| Matric | Secondary school certificate (Classes 9–10) |
| Royalty | Head office share of a franchise's monthly fee collection |
