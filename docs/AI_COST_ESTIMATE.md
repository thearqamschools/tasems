# AI features (M13) — service and cost estimate (22 Oct 2026)

**Not switched on. Nothing is bought until the project lead approves the provider and a monthly spending cap
(D-060).**

## Service

Claude API from Anthropic (usage-based: you pay only for what is used; no fixed monthly fee). Needs an Anthropic
account with a payment card and prepaid credit; a monthly spending limit can be set in the Anthropic Console so the
bill can never go above it.

## Prices (Anthropic list prices, US$ per 1 million tokens; ~1 million tokens ≈ 700,000 English words)

| Model | Input | Output | Use |
|---|---|---|---|
| Claude Opus 5.5 | $4.00 | $20.00 | Best quality: question papers, teacher assistant |
| Claude Sonnet 5.5 | $2.00 | $10.00 | Half the cost; good for most school tasks |
| Claude Haiku 5.5 | $0.10 | $0.50 | Very cheap; short summaries, simple checks |

## Rough cost per use (Opus 5.5, including the model's own reasoning)

| Task | Approx. tokens (in / out) | Approx. cost |
|---|---|---|
| One question paper from a textbook chapter | 5,000 / 6,000 | ≈ $0.14 |
| One teacher-assistant question and answer | 2,000 / 1,500 | ≈ $0.04 |
| One student or class summary for parents/principal | 3,000 / 800 | ≈ $0.03 |

## Example month (assumption, to be replaced by real usage)

Per branch: 20 question papers + 100 teacher-assistant questions + 100 summaries ≈ $10 with Opus 5.5
(≈ $5 with Sonnet 5.5, ≈ $0.30 with Haiku 5.5).

| Branches using AI | Opus 5.5 | Sonnet 5.5 | Haiku 5.5 |
|---|---|---|---|
| 1 (pilot) | ≈ $10 | ≈ $5 | < $1 |
| 30 | ≈ $300 | ≈ $150 | ≈ $9 |
| 300 | ≈ $3,000 | ≈ $1,500 | ≈ $90 |

Costs fall further with prompt caching (repeated textbook text is billed at a tenth) and batch processing (half
price for work that can wait). Rupee figures depend on the exchange rate on the day of payment.

Recommended start: a pilot in one or two branches with a low spending cap, then decide from the real bill.
The free "at-risk students" analytics (attendance, marks, fees) need no paid service.
